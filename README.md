# PlabFootball Backend

플랩풋볼 서비스 분석 및 개선을 위한 CEOS Mashup Day 백엔드 프로젝트입니다.

## Requirements

- Java 21
- Gradle Wrapper
- MySQL

## 개발 환경

| **항목** | **구성** |
| --- | --- |
| Spring Boot | 4.1.1 |
| Gradle | Wrapper 9.7.1 |
| HTTP / 입력 검증 | Spring Web MVC / Validation |
| 데이터 저장 | Spring Data JPA / MySQL |
| API 문서 | Springdoc OpenAPI 3.1.1 / Swagger UI |
| 반복 코드 생성 | Lombok |
